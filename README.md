# MERN Stack Project

A full-stack MERN application built using **MongoDB**, **Express**, **React**, and **Node.js**. This README covers setup, environment variables, scripts, and how to run the project in both development and production.

---

## Tech Stack
- **Frontend:** React + Vite, JavaScript, BootStrap - 5  
- **Backend:** Node.js, Express, JavaScript, Mongoose
- **Database:** MongoDB (Local or MongoDB Atlas)

---
## Prerequisites
Make sure you have installed:
- Node.js v18+
- npm / yarn / pnpm
- MongoDB locally OR a MongoDB Atlas cloud database
- Git

### Clone the repo
```bash
git clone <your-repo-url>
cd <project-folder>

cd server && npm install
cd ../client && npm install

```

### Run Backend
- cd server
- nodemon server.js

### Run Frontend
- cd client
- npm run dev
